Privacy policy

gws-cli is a personal command-line tool. Its only user is its developer, who uses it on their own computer to access their own Google account.

  • Google user data (Drive files, Sheets, Docs, Gmail messages and profile) is accessed only on the user's own machine, at the user's request.
  • No data is sent to, stored on, or shared with any server other than Google's own APIs.
  • OAuth tokens are stored encrypted on the user's machine only.
  • No data is sold, used for advertising, or used to train models.
  • Access can be revoked at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
